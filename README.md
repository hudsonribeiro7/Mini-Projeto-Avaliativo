# Pokédex TypeScript

Mini projeto de uma Pokédex desenvolvido com Node.js e TypeScript.

## Objetivo

O objetivo do projeto é buscar informações de Pokémon através da PokeAPI e criar um catálogo local em memória.

O projeto permite buscar, adicionar, listar e remover Pokémon.

## Tecnologias utilizadas

- Node.js
- TypeScript
- PokeAPI
- Git e GitHub

## Pré-requisitos

É necessário ter o Node.js instalado.
